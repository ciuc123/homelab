# SEO audits

Written by the "SEO audit" workflow: `audits/<host>/<YYYY-MM-DD>.md` (the report) and `.json` (the data the next audit
of the same site compares against). One audit per site per day; a second run on the same day replaces the first.

To audit a site: open an issue with the **SEO audit** form (target site, optional max pages and client name), or
Actions → SEO audit → Run workflow. To re-audit, open a new issue: the report shows the score change since the last one.

This repository is public, so these reports are too.
